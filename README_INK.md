# 阅读 · 纸墨前端重构

基于开源阅读 [Legado](https://github.com/gedoor/legado)（提交 `da17bb2`）重做全部前端界面，风格叫「纸墨」。
只改前端：布局、样式、`ui/` 下的展示代码和默认主题配置。书源、规则解析、网络、数据库和阅读排版引擎都没有动。

本项目是 Legado 的衍生作品，按 **GPL-3.0** 发布，许可证见 `LICENSE`。

## 主要内容
- **立体书架**：3D 书架视图，书脊朝外、封面朝前，台灯光晕、木质层板、底部书签尺可拖动定位。
- **书柜式分组**：每个分组是书柜的一层，层板上有铜铭牌，上下拖动换层。分组名由使用者自己定（分组管理里新建）。
- **书柜总览**：在立体书架上双指合拢，收成一座胡桃木书柜，一层一类；点一层放大进入。「标签」和「文件夹」两种分组样式都支持。
- **其余页面重做**：主页浮动底栏、我的、发现、订阅、书籍详情、目录、阅读菜单（浮动卡片）、阅读样式面板、对话框等，日夜两套主题。
- **阅读样式**：新增「纸墨」预设（纸纹背景、衬线字）；启动页书法字标；新应用图标。
- 封面规则：有书源封面或自定义封面就用它，没有就用默认封面。

## 构建
实验包与原版共存（包名 `io.legado.app.shelf3d`），构建时加 `-Pshelf3d`：

```
./gradlew :app:assembleAppDebug -Pshelf3d
```

## 书源
安装包里只有原版自带的少量默认书源。本仓库不附带书源文件，请在应用里自行导入。
